## Mathematical basis

A vertex represents an original item or treatment. A letter represents a clique. True twins with identical closed neighborhoods form a reduced vertex with a weight equal to the number of original vertices. Distinct isolated vertices must not merge.

Every clique lies inside a maximal clique. For C, extending each letter to a maximal clique preserves validity and cannot increase the number of letters. Duplicate maximal cliques can merge. Thus the whole maximal clique selection model contains an optimum.

For sigma, each letter can be assigned to a containing maximal clique. If several letters use the same containing maximal clique, merge their vertex sets. Their union is still a clique and costs no more assignments. Thus one variable letter per maximal clique contains an optimum. Its membership variables permit any subset, including the empty set. The weighted reduction also needs the reverse direction: an optimum exists with equal letter sets for true twins, and the canonical optimum has that common row. The proof is in `docs/algorithm.md`, section 3, lines 101 to 103 at the source head. Positive reduced vertex weights then preserve the expanded assignment objective. These arguments preserve the minimum objective; preserving the chosen canonical optimum needs the existing ordering proof as well.

The current model does not supply the full cover as a MIP start. It gives HiGHS binary choices and coverage constraints. C selects whole maximal cliques. Sigma selects memberships within those cliques, with edge witness variables. This avoids separate constraints for incompatible pairs inside a letter. The essential scan fixes only decisions that every feasible solution of this model must use. It does not make optional deletions independent or perform FIND-AM backtracking.

The full maximal cover gives a feasible upper bound on letter count and weighted assignments. The current binary bounds already imply those bounds. Adding the same loose objective cap is not a performance improvement by itself. A supplied feasible MIP start is a separate experiment and needs a supported adapter API and measured benefit.

### Exact primary cost deductions

After the first optimal solve, let z be the certified primary minimum. Let F be the sum of costs of every decision already fixed to 1, including essential decisions at future canonical positions. A free decision with positive integer cost w cannot be 1 when F + w > z. Fix it to zero without an infeasible trial. When F equals z, all remaining positive cost decisions must be zero. The current feasible incumbent remains a witness for every such fixing.

Count each fixed variable once. Use original objective weights and decision indices only, never auxiliary variables. Check the shared deadline during the deduction loop. Validate the selected vector as before. If F exceeds z, fail through the invalid solution path. This implication requires nonnegative objective terms and known positive cost on the proposed decision; retain the ordinary solve path if a future strategy does not satisfy those assumptions. Do not infer that all other free assignments are jointly removable.

Prove this implication from the cost cap, then compare against the unmodified canonical engine over existing exhaustive fixtures and weighted cases. ## Other candidates when their stage dominates

If canonical trials dominate on a connected graph, evaluate a proof based reduction in the number of solves. This can be the first runtime candidate; it need not wait for an unpromising model reuse experiment. One bounded candidate is blockwise exact lexicographic optimization after the primary optimum is fixed. For a small block of b ordered free binary decisions, minimize the negative integer score with coefficients -2^(b-1), ..., -1, then fix that block before the next block. This is equivalent to maximizing the positive score and keeps the solver in minimization mode. The installed R highs 1.14.0.2 wrapper has a broken `$maximum(TRUE)` method; do not use it. Test the sign and exact selected score in each language. Keep the original primary cost cap at z. Store original primary costs separately from the temporary block objective. Do not let a block objective overwrite the cap coefficients, returned primary objective, or primary validation. The first different bit dominates the sum of all later block weights, so an exact block optimum selects the same lexicographic prefix. A proof must also cover fixed positions and zero cost auxiliary variables. Require optimal status for every block, small bounded coefficients (initial experiments b = 4, 8, 12, or 16), exact gap settings, integer score validation, original cost validation, and independent exhaustive canonical equivalence. No giant whole-vector weights or epsilon perturbations. Treat block size as a benchmark parameter selected before the validation run. Fewer calls may still cost more search; retain the reference if full time loses. It is a separate candidate from session reuse. Choose it first if profiling supports it, and keep its proof and implementation in one focused PR.

If sigma search remains costly, test continuous edge witness variables as another isolated model candidate. Keep all membership decisions binary. Conversely, any covered edge can use one witness equal to 1. Thus relaxing only these zero cost witnesses from binary to [0,1] preserves the feasible membership vectors and canonical optimum. It may not improve speed because presolve can already exploit this structure. Benchmark it and keep it only if it passes the gate.
