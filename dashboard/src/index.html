Input

This page reads significance decisions. It does not run significance tests. A group is one item or treatment.

Examples

One row for each pair of groups, with the columns group1, group2, and significant. The decision is true when the two groups differ significantly. Every pair needs a row.

or .

Columns group and mean. The means set the order of the groups and of the letters. They do not change a decision.

or .

Method

CLD-C gives the fewest distinct letters. CLD-sigma gives the fewest assignments of a letter to a group. Neither method optimizes the other quantity as a second objective.

Licenses and data sources

The page holds the cld-reducer JavaScript package, the HiGHS solver from the npm package highs, and both example data sets.
